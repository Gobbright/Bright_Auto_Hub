# Top Brands logo sources

The Home page brand marks are local SVG downloads so the marquee does not depend on third-party runtime requests.

- Suzuki, Hyundai, Tata, Mahindra, Toyota, Honda, Kia, MG, Skoda and Volkswagen: Simple Icons CDN (`https://cdn.simpleicons.org/`). Simple Icons is a CC0 project; brand marks can still be protected trademarks.
- Bajaj Auto: Wikimedia Commons, `File:Bajaj Auto logo.svg` (public-domain text/logo mark; trademark notice applies).
- Hero MotoCorp: Wikimedia Commons, `File:Hero MotoCorp Logo.svg` (public-domain text/logo mark; trademark notice applies).
- TVS Motor: English Wikipedia, `File:TVS Motor logo.svg`.
- Ashok Leyland: English Wikipedia, `File:Ashok Leyland logo.svg`.

All fourteen local files are also stored in the Admin Image Gallery (MongoDB GridFS) with context `home-top-brand-logo`.
